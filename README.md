# Royalty Report Toolkit｜音乐版权收益报表工具箱（ChatGPT 脱敏过）

音乐版权收益报表处理工具箱。**24 号「报表进度台」是整个工作流的主入口**，用来追踪每份报表从除错、重新比对到拆分对账的进度。其他编号工具负责 Excel 回填、筛选、拆分、汇总等具体操作，20 号负责网站比对与汇出。

## 核心功能 · 24 号报表进度台

- **阶段和轮次**。以原报表建立项目，按「系统汇出 → 送入系统」登记每轮除错。两步登记完才进入下一轮，确认除错完成后进入拆分阶段。
- **拆分与金额对账**。保留原项目名称，把拆出的报表登记为子项目。对账时读取各分支当前版本的金额，加总后与原始总金额核对。
- **版本与备份**。总项目和子项目各自记录备份。登记系统汇出时自动复制原文件，送入系统的版本可附修改备注。需要返工时，可以打开历史文件，或将分支切回旧版本再对账。
- **连接系统比对**。总项目和分支可以分别登记报表 ID。「打开系统页面」直达报表页。「开始比对」调用 20 号，在已有比对完成后上传登记的 Excel，等待新一轮比对并下载结果。

**本地体验**。Mac 双击 `运行-24报表进度台.command`，Windows 可运行 `python "24 报表进度台.py"`。也可以运行 `python demo.py`，用虚构数据查看多轮除错、拆分、版本回切和对账。公开版的系统地址为示例域名。

## 推荐流程

**行序（05）**

1. 弹窗选系统原始报表，跑 **05 建档行序**（写回 + `00-原始基准/` 留副本）。
2. 行序乱了时，弹窗选文件跑 **05 恢复行序**（写回原文件）。

**01 / 02 可见行模式**：在第一个页签筛选后保存并关闭 Excel。脚本询问范围时选「是」仅处理可见行，选「否」处理全部行。02 会用同一范围补齐缺少的 01 匹配结果。

**01 → 02 → 14（收益时间）**：比对表放 `01-vlookup-比对表/`，弹窗选主报表跑 **02**（缺 VLOOKUP 四列会自动先跑 01）。02 完成后同目录有 `_收益时间错误汇总.xlsx`；跑 **14** 勾选要忽略的 C/D 分组 → 主报表清空对应「比對結果」「错误类型」，未勾选的写入 `_收益时间聚焦.xlsx` 供人工处理。单行忽略可在 Excel 里直接清空「比對結果」。

**15 → 16（词曲比对 false）**：弹窗选主报表 → 导出 `_词曲比对false汇总.xlsx` 与 `_词曲比对false聚焦.xlsx`（E 列默认「待处理」，主报表不改）。人工看完某分组后删掉该行「待处理」，再跑 **16** 把对应 C/D 的 false **清空**。

**03 / 04 / 06～13**：运行时弹窗选路径即可。

**00**：多选要归档的 Excel，再选导出目标文件夹（默认可选 `00-最终导出/`）。

## 运行方式

首次设置或更换默认目录时，Mac 双击 `运行-22设置默认目录.command`，Windows 双击 `运行-22设置默认目录.bat`。选定文件夹后，下次打开工具箱的输入文件或文件夹选择窗口时会从该目录开始。取消选择会保留现有设置。目录不可用时，选择窗口回到桌面。

运行前请关闭 Excel。

脚本跑完后会显示 **「按 Enter 键关闭窗口...」**，回车后再退出，方便查看输出。

```powershell
python "05 建档行序.py"
python "01 excel_vlookup.py"
python "02 半自动除错.py"
# … 其余脚本同理
```

Windows 上 03 / 05 / 06 / 09 / 11 / 18 会自动使用 Excel COM 加速；Mac 使用 openpyxl。COM 运行中会实时刷进度（打开 / 写公式 / 复制 / 保存），不会长时间无输出。

## 大报表分段（10 万行/段）

共享模块 `report_chunk.py`。数据行超过 10 万时**不会退出**，每次只处理一段：

1. 弹窗确认总行数
2. 超过一段时选择要处理的段（第 1～10 万、第 100001～20 万 …）
3. **每段完成后弹窗询问是否继续下一段**（选「否」可暂停，进度保留）
4. 首段自动备份，并创建 `{文件名}.chunkwork.xlsx` 工作文件
5. **中间段只写工作文件，原文件不动**
6. **全部段都跑完后**，才写回最终文件并删除工作文件 / 进度文件

**备份命名规则（时间戳）**：

```
report.xlsx  →  report.bak-YYYYMMDD.xlsx
```

- 同一天重复运行会覆盖同名备份（不会每天堆一个）。
- **恢复方法**：把文件名里的 `.bak-YYYYMMDD` 那段删掉、改回原扩展名即可还原，例如 `report.bak-20260929.xlsx` → `report.xlsx`。
- 该命名同时让 git 不会误提交业务备份：`.bak-YYYYMMDD` 后缀既不命中 `*.bak` 规则、又以 `.xlsx` 结尾落在业务文件忽略规则内。

| 01 / 02 / 04 / 07 / 09 / 14 | 写回用户选的 Excel |

段选择列表中 `✓` 表示该段已完成。09 各步骤进度独立（如 `09-return`）。

03 / 05 / 06 / 08 为整表或 COM 全量，暂不分段。

## 21 TME 报表合并

Mac 双击 `运行-21TME报表合并.command`，Windows 双击 `运行-21TME报表合并.bat`。打开存放各期报表文件夹的上级目录，在列表里多选要处理的子文件夹。选好源文件夹后，再选一个统一输出目录，每个源文件夹各生成一份 `文件夹名_TME合并.xlsx`。输出重名时保留已有文件，并继续处理其他文件夹。命令行可传入多个源文件夹，通过 `--output-dir` 指定统一输出目录。

文件名按去掉扩展名后的前缀和平台代码匹配，忽略大小写。依次处理 `mv`、`song`、`single`、`k`、`aiting` 和 `album`。分平台的类别依次按 `qq`、`kg`、`kw` 排列，平台代码可出现在文件名末尾，也可作为下划线分隔的一段，例如 `_qq_`。`k` 对应 K歌及直播，`aiting` 对应爱听，两者均无需平台代码。缺少对应文件时跳过，多个文件命中同一页签时提示具体文件名。

支持 `.xlsx` 和 `.xlsm`。每个文件取第一张工作表的单元格值和数字格式，公式取计算值（Mac 读取源文件已有的公式缓存）。数字专辑默认前缀为 `album`，可通过命令行指定，例如 `python "21 TME报表合并.py" "/路径/报表文件夹" --album-prefix digitalalbum`。
